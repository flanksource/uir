One model for every codebase you run.

UIR is the Universal Intermediate Representation. It lowers Go, SQL routines, XML, and domain-specific sources into one model of code. Index a repository once, then query symbols, trace calls, enforce SQL rules, and diff changes across commits.

What UIR does

Many sources, one model

Lower Go, PL/pgSQL, T-SQL, and XML, or publish symbols and relationships from your own domain.

Snapshot indexing

Build immutable snapshots in SQLite or PostgreSQL with uir add and uir reindex.

Query with selectors or SQL

Find symbols and follow relationships, or use SQL to query metrics and aggregate results.

Bounded call graphs

Explore callers and callees to a set depth and see the conditions around each call.

SQL lint rules

Enforce architecture rules in CI and report violations at the source line.

Rename-aware diffs

Compare symbols across Git commits and see changes to signatures, structure, and bodies.

One model answers many questions

Index and query a Go module

After installing the CLI, run uir add from a Go module, then find a function and its callers. Replace Run with the function you want to trace.

uir add .
uir query 'func:Run <'
