# UIR

Universal Intermediate Representation is a language-agnostic model for describing code: modules, packages, types, methods, records, tables, endpoints, and the statements inside method bodies. Extractors emit UIR; generators and analysers consume it.

The Go package is the canonical model, with parallel Python and Java ports. The CLI indexes Go modules into immutable snapshots so you can navigate symbols, trace call relationships, and compare revisions.

## Use the model

```go
import "github.com/flanksource/uir"
```

The [model reference](/model) covers nodes, statements, builders, identifiers, and serialization. [Symbols and references](/symbols) explains identity and reference resolution; [storage](/storage) describes persisted snapshots and the database schema.
